# 机器人行业技能树

交互式成就树，帮助规划进入机器人行业的学习路径。

## 使用方式

加载此 skill 后：
- **查看技能树** → 直接在浏览器打开 `skill-tree.html`
- **更新招聘信息** → 告诉我"抓取最新机器人招聘"，我会搜索并更新数据
- **检查进度** → 打开 HTML 页面即可看到打卡状态（浏览器 localStorage 持久化）
